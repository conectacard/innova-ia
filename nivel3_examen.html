Examen Final - Nivel 3

Introducción al Desarrollo Profesional con VS Code y Lógica Web

Responde las 10 preguntas. Necesitas al menos un 70% de aciertos para desbloquear tu diploma institucional.

1. ¿Cuál es el propósito principal de utilizar VS Code como entorno de desarrollo en este nivel?

2. ¿Qué tecnologías conforman la base de la estructura web moderna y el diseño responsivo en dispositivos móviles?

3. En el contexto de la programación esencial con JavaScript, ¿para qué se utilizan elementos como variables, eventos y la manipulación del DOM?

4. ¿Qué función principal cumplen asistentes de código como GitHub Copilot y DeepSeek integrados en VS Code?

5. ¿Qué define a una Aplicación Web Progresiva (PWA) en su estructura local básica?

6. ¿Cómo se logra la integración multimedia dentro del código fuente de una página web en este nivel?

7. Al utilizar atajos y extensiones óptimas en VS Code, ¿qué busca principalmente el desarrollador?

8. ¿Qué rol juega el lenguaje CSS3 cuando se combina con HTML5 en el desarrollo web moderno?

9. ¿Qué permite hacer la manipulación del DOM (Document Object Model) mediante JavaScript?

10. Al cierre del Nivel 3, además de la evaluación final, ¿qué demostración práctica debe presentar el alumno?
